# 伟大航路粉丝站

海贼王主题的 HTML、CSS、JavaScript 学习项目。本仓库是项目后续开发与维护的主仓库。

- [访问网站](https://zhangpf-hub.github.io/one-piece-fan-site/)
- [直接访问原有页面](https://zhangpf-hub.github.io/one-piece-fan-site/StudyDanDan/)

## 目录

```text
one-piece-fan-site/
├── index.html         # 网站首页入口，跳转至 StudyDanDan/
├── README.md
└── StudyDanDan/
    ├── index.html     # 网站页面
    ├── style.css      # 页面样式
    └── script.js      # 页面脚本
```

## 开发与发布

直接编辑 `StudyDanDan/` 中的文件。本项目不需要安装依赖或编译，本地可用浏览器打开 `StudyDanDan/index.html` 查看。

网站通过 GitHub Pages 发布，来源为 `main` 分支的根目录。推送修改后，等待 Pages 发布完成即可查看更新。
